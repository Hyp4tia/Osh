# Keyboard Shortcuts & Navigation

Osh provides standard macOS keyboard shortcuts for navigation, reading, editing, and exporting documents.

---

## ⚡ Finder QuickLook

| Action | Shortcut | Description |
|:---|:---:|:---|
| **Quick Look Preview** | `Space` | Preview selected Markdown (`.md`, `.markdown`) or `.skill` file in Finder |
| **Close Quick Look** | `Space` / `Esc` | Dismiss the QuickLook preview window |
| **Full Screen Preview** | `⌥` + `Space` | Open QuickLook directly in fullscreen |

---

## 📖 Document Reader & Editor

| Action | Shortcut | Description |
|:---|:---:|:---|
| **Toggle Editor / Preview** | `⌘` + `E` | Switch between live rendered view and raw Markdown editor |
| **Open File** | `⌘` + `O` | Open a `.md` or `.skill` document via file picker |
| **Save Document** | `⌘` + `S` | Save current changes (preserves original package for `.skill` files) |
| **Find in Document** | `⌘` + `F` | Open the in-page search bar |
| **Find Next / Previous** | `⌘` + `G` / `⇧` + `⌘` + `G` | Jump to the next or previous search result |
| **Zoom In** | `⌘` + `+` (or `⌘` + `=`) | Increase document text and diagram scale |
| **Zoom Out** | `⌘` + `-` | Decrease document text scale |
| **Reset Zoom** | `⌘` + `0` | Reset zoom to 100% default scale |
| **Open Settings** | `⌘` + `,` | Open the Osh Preferences and Theme window |
| **Export Document** | `⇧` + `⌘` + `E` | Open the Export dialog (PDF, HTML, DOCX) |
| **Help Guide** | `⌘` + `?` | Open localized user documentation |
| **Close Window** | `⌘` + `W` | Close the active viewer window |
| **Quit Osh** | `⌘` + `Q` | Quit the application |

---

## 🧭 Mouse & Trackpad Gestures

- **Pinch to Zoom**: Pinch on your trackpad to smoothly scale the document.
- **Table of Contents Jump**: Click any heading in the TOC sidebar to smoothly scroll to that section.
- **Link Navigation**: Click local relative Markdown links to jump between files in the same directory.
